# README language sync

When changing the root `README.md`, update the corresponding content in the root `README.en.md` in the same task. Translate the meaning, not the wording: preserve facts, commands, links, images, and the intended level of detail while writing natural English.

Keep section placement and quick-navigation links aligned. If a heading changes, check the matching anchor in each language. Inspect the relevant diff in both files so existing, unrelated edits remain intact.

Follow an explicit user instruction to change only one language when they provide one.
